შეკვეთების რვეული — მზადაა Cloudflare-ზე გასამართად

რა მუშაობს
• კლიენტის სახელი და გვარი, პროდუქტი, ფასი, ქალაქი/რეგიონი,
  ზუსტი მისამართი, ტელეფონი, გაგზავნის თარიღი, მიტანის დრო, შენიშვნა.
• პატარა გასაშლელი ბარათები, ძებნა და რედაქტირება.
• დღეს გასაგზავნი თავში; სხვა შეკვეთები ახალი ჩანაწერიდან ძველისკენ.
• გაგზავნილად მონიშვნა და გასაგზავნებში დაბრუნება.
• შეკვეთები ინახება Cloudflare D1-ში; იმავე საიტსა და პაროლზე სხვა ტელეფონიდანაც ჩანს.
• აპის დაყენება მთავარ ეკრანზე და ყოველდღიური Web Push შეხსენება.
• შეხსენება 12:00-ზე თბილისის დროით (0 8 * * * UTC), მხოლოდ იმ დღის გაუგზავნელ შეკვეთებზე.

GitHub-იდან Cloudflare Workers Builds
Worker-ის სახელი: sales. D1 საცავი უკვე შექმნილია და wrangler.json-ში მიბმულია.
განახლების deploy command: npm run deploy:ci
პაროლი და შეტყობინების გასაღებები Cloudflare-ის პირად secrets-შია შენახული.

ატვირთვა — Windows-ზე ყველაზე მარტივი გზა
1. ZIP გაშალე ცალკე საქაღალდეში.
2. ორჯერ დააჭირე upload-to-cloudflare.cmd-ს.
   თუ Node.js არ გაქვს, დააყენე LTS ვერსია https://nodejs.org-დან.
3. ბრაუზერში Cloudflare-ის შენს ანგარიშზე შედი და დაადასტურე ავტორიზაცია.
4. ფანჯარა მოგთხოვს საიტის მოკლე სახელს (ლათინურად) და ელფოსტას.
   პირად ZIP-ში შესასვლელი პაროლი უკვე მომზადებულია .initial-password ფაილში.
   GitHub-იდან ჩამოტვირთვისას ეს პირადი ფაილი არ არის; გამართვისას მიუთითე შეთანხმებული პაროლი.
   ელფოსტა გამოიყენება Web Push-ის საკონტაქტო მისამართად; კლიენტებს წერილები არ ეგზავნებათ.
5. გამშვები ქმნის საცავს, მის ცხრილებს, შეტყობინების გასაღებებს და 12:00-ის განრიგს.
6. ბოლოს გამოჩნდება https://....workers.dev მისამართი — ეს არის შენი საიტი.

იგივე ხელით, საქაღალდეში ტერმინალიდან:
  npm ci
  npm run deploy

ეს არის Cloudflare Workers + D1 პროექტი. სრული შესაძლებლობებისთვის გამოიყენე ზემოთ აღწერილი გამართვა.
Cloudflare Pages-ში მხოლოდ public საქაღალდის გადატანით შეკვეთების საცავი და
12:00-ის შეხსენება არ ჩაირთვება. საჭიროა Cloudflare Worker + D1.

ტელეფონში დაყენება
Android / Chrome: საიტის მენიუ ⋮ → Install app / Add to Home screen.
iPhone / Safari: Share → Add to Home Screen, მერე აპი გახსენი მთავარი ეკრანიდან.
iPhone-ზე Web Push-ისთვის საჭიროა iOS 16.4 ან ახალი ვერსია.
საიტზე ზარის ღილაკს დააჭირე → შეხსენების ჩართვა → ნებართვა მიეცი.
ჩართვის შემდეგ შეგიძლია „საცდელი შეტყობინება“ გაგზავნო.
შეტყობინებაზე დაჭერა გახსნის დღევანდელ შეკვეთებს.
დახურულ აპზეც შეხსენებას სერვერი აგზავნის; მიღების დრო დამოკიდებულია ინტერნეტზე,
ტელეფონის შეტყობინებების პარამეტრებზე და შეტყობინების სერვისზე.
თუ იმ დღეს გასაგზავნი შეკვეთა აღარ დარჩა, შეტყობინება არ გაიგზავნება.

პაროლი და გასაღებები
გამართვისას იქმნება deployment-secrets.json. შეინახე პირადად.
ეს ფაილი არც public საქაღალდეშია და არც ZIP-შია ჩადებული.
მომდევნო ატვირთვა ამავე საქაღალდიდან ინარჩუნებს საცავსა და შეტყობინების გასაღებებს.
უკვე ატვირთული პროექტის განახლებისთვის კვლავ გაუშვი npm run deploy.
პაროლის შეცვლისთვის Cloudflare → Worker → Settings → Variables and Secrets → APP_PASSWORD.
შეცვლილი პაროლი განაახლე შენს პირად deployment-secrets.json-შიც, რომ შემდეგ ატვირთვაზე ძველი არ დაბრუნდეს.

გამოყენება
„ახალი შეკვეთა“ → შეავსე ველები → „შენახვა“.
ბარათზე დაჭერა სრულ ინფორმაციას ხსნის; ტელეფონზე დაჭერა ზარისთვისაა.
„გაგზავნილად მონიშვნა“ გადააქვს გაგზავნილებში და დღევანდელი შეხსენებიდან ხსნის.
დაგვიანებულ შეკვეთას წითელი ნიშანი აქვს და „სხვა შეკვეთებში“ რჩება.
ქალაქი/რეგიონი შეგიძლია სიიდან აირჩიო ან საკუთარი ტექსტი ჩაწერო.
შეკვეთის შესანახად ინტერნეტი საჭიროა. გათიშვისას შევსებული ფორმა დარჩება,
რომ დაკავშირების შემდეგ შენახვა ხელახლა სცადო; ასეთი ფორმა შენახული შეკვეთა ჯერ არ არის.
საიტი ცარიელი შეკვეთების სიით იწყება. საჩვენებელი შეკვეთები არ არის.
