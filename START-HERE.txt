შეკვეთების რვეული — რა შეიცვალა და როგორ ავტვირთო
===================================================

ახალი მისამართი: https://sales.pages.dev
ძველი მისამართი (sales....workers.dev) ავტომატურად ახალზე გადაიყვანს.


რა შეიცვალა
-----------
• საიტი პირდაპირ ცარიელ რვეულს ხსნის. ყალბი, საჩვენებელი მონაცემები აღარ არის.
• ყველას თავისი რვეული აქვს. სხვისი შეკვეთები არავის უჩანს.
• რეგისტრაციის გარეშეც მუშაობს: პირველ შეკვეთას რომ ჩაწერ, ამ ბრაუზერის
  რვეული სერვერზე შეინახება და მხოლოდ ამ ბრაუზერიდან გაიხსნება.
• 12:00-ის შეხსენება რეგისტრაციის გარეშეც ირთვება (ზარის ღილაკი).
• რეგისტრაცია (ელფოსტა + პაროლი, ან Google) იმავე რვეულს ინახავს და
  ნებისმიერი ტელეფონიდან თუ კომპიუტერიდან გახსნის საშუალებას იძლევა.
• ერთ ექაუნთში რამდენიმე ადამიანს შეუძლია მუშაობა. შესვლისას ყველა თავის
  სახელს ირჩევს ან ამატებს. თითოეულ შეკვეთაზე ჩანს, ვინ ჩაწერა, ვინ
  შეცვალა და ვინ გაგზავნა.
• ძველი საერთო პაროლი აღარ არის, ძველი შეკვეთები აღარ ჩანს და ფაილის
  პირველივე გაშვებისას წაიშლება. დედაშენი თავიდან დარეგისტრირდება
  (მაგალითად Google-ით).


როგორ ახლდება
-------------
• GitHub-ზე ატვირთვისას საიტი თავისით ახლდება (თუ Cloudflare-ში GitHub
  მიბმულია). ძველ მისამართზე ახალი ვერსია მაშინვე გამოჩნდება.
• ერთხელ აუცილებლად გაუშვი ფაილი upload-to-cloudflare.cmd. ის:
    – ქმნის ახალ მისამართს sales.pages.dev,
    – ინახავს შეხსენების და Google-ის გასაღებებს,
    – ძველ მისამართს ახალზე გადამისამართებს,
    – შლის ძველ შეკვეთებს და ძველ პაროლს.
  ამის შემდეგ ყოველი GitHub-ზე ატვირთვა ახალ მისამართსაც აახლებს. ფაილი
  თავიდან მხოლოდ მაშინ დაგჭირდება, თუ Google-ის გასაღებებს დაამატებ ან
  შეცვლი.


ფაილის გაშვება
--------------
1. ორჯერ დააჭირე ფაილს: upload-to-cloudflare.cmd
2. თუ ბრაუზერი გაიხსნება და Cloudflare დასტურს გთხოვს, დააჭირე Allow.
3. თუ Google Client ID-ს გკითხავს და ჯერ არ გაქვს, უბრალოდ Enter დააჭირე.
   Google-ით შესვლას მოგვიანებით ჩართავ (იხ. ქვემოთ).
4. თუ ინგლისურად გკითხავს „continue?“, დააჭირე Enter-ს.
5. ბოლოს ეწერება: „მზადაა! საიტი: https://sales.pages.dev“.


Google-ით შესვლის ჩართვა (ერთხელ, ორივე საიტისთვის ერთად)
---------------------------------------------------------
1. გახსენი https://console.cloud.google.com და შედი შენი Google ექაუნთით.
2. ზემოთ, პროექტის არჩევაში: New Project → სახელი, მაგ. WebCraft Apps → Create.
3. მენიუდან გახსენი „Google Auth Platform“ (ძველ ვერსიაში „OAuth consent screen“):
   • Branding: App name — მაგ. „შეკვეთების რვეული“, User support email — შენი
     ელფოსტა. თუ Authorized domains-ს მოითხოვს, დაამატე:
     sales.pages.dev და javshnebi.pages.dev
   • Audience: External, მერე დააჭირე Publish app, რომ ყველამ შეძლოს შესვლა.
4. Clients → Create client → Application type: Web application.
   Authorized redirect URIs-ში დაამატე ორი ხაზი:
     https://sales.pages.dev/auth/google/callback
     https://javshnebi.pages.dev/auth/google/callback
   → Create.
5. გამოჩნდება Client ID და Client Secret. შეინახე სადმე პირადად.
6. ხელახლა ორჯერ დააჭირე upload-to-cloudflare.cmd-ს და როცა გკითხავს,
   ჩასვი Client ID და Client Secret. იგივე გაიმეორე აგარაკის საქაღალდეშიც.
   ამის შემდეგ საიტზე „Google-ით გაგრძელება“ ღილაკი გამოჩნდება.


კარგი იქნება, თუ იცი
--------------------
• პაროლის აღდგენა ელფოსტით ჯერ არ არის. თუ სადმე უკვე შესული ხარ, ახალ
  პაროლს პარამეტრებიდან დააყენებ. Google-ით შესულს პაროლი არ სჭირდება.
• დაურეგისტრირებელი რვეული ბრაუზერის „ქუქიზეა“ მიბმული. ბრაუზერის
  მონაცემების წაშლისას ის ვეღარ გაიხსნება, ამიტომ საიტი რეგისტრაციას
  ურჩევს. 6 თვე გამოუყენებელი დაურეგისტრირებელი რვეულები თავად იშლება.
• თუ ვინმე უკვე არსებულ ექაუნთში შევა იმ ბრაუზერიდან, სადაც რეგისტრაციამდე
  შეკვეთები ჩაწერა, საიტი ჰკითხავს, გადმოიტანოს თუ არა ისინი ექაუნთში.
• ტელეფონზე აპის ხატულა თავიდან უნდა დაამატო ახალი მისამართიდან, რადგან
  მისამართი შეიცვალა. შეხსენებაც თავიდან ჩართე ზარის ღილაკით.
• უფასო გეგმაზე დღეში ბევრი მომხმარებელიც დაეტევა. თუ საიტი ძალიან
  გაიზრდება, Cloudflare-ის ფასიან გეგმაზე (5$/თვე) გადასვლა დაგჭირდება,
  რომ ყველას 12:00-ზე ზუსტად მიუვიდეს შეხსენება.
• deployment-secrets.json პირადი ფაილია (შეხსენების და Google-ის გასაღებები).
  არ წაშალო და არავის გაუზიარო. GitHub-ზე არ იტვირთება.
