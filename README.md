# შეკვეთების რვეული

ქართული შეკვეთების მართვის აპი Cloudflare Workers-ზე, D1 საცავით და ყოველდღიური Web Push შეხსენებით.

- შეკვეთების დამატება, ძებნა, რედაქტირება და გასაშლელი ბარათები.
- დღეს გასაგზავნი შეკვეთები თავში; დანარჩენი ახალი ჩანაწერიდან ძველისკენ.
- გაგზავნილი შეკვეთების ცალკე სია.
- პაროლი პირველ შესვლაზე, მოწყობილობაზე დამახსოვრებული შესვლით.
- ტელეფონის მთავარ ეკრანზე დაყენება და შეხსენება 12:00-ზე, თბილისის დროით.

## GitHub-იდან Cloudflare Workers Builds

Worker-ის სახელია `sales`. `wrangler.json` უკვე შეიცავს ამ საიტისთვის შექმნილი D1 საცავის ნამდვილ ნომერს. წარმოების საცავი ცარიელია და მაგალითები ავტომატურად არ ემატება.

განახლებებისთვის deploy command მიუთითე `npm run deploy:ci` — ჯერ საჭირო ცხრილებს განაახლებს და მერე საიტს ატვირთავს. არსებული `npx wrangler deploy` ამ გამზადებულ საცავზეც მუშაობს.

შესასვლელი პაროლი და Web Push გასაღებები უკვე გამართულია Cloudflare-ის secrets-ში. GitHub-ში პაროლი არ ინახება.

## Cloudflare-ზე გამართვა

Windows-ზე გაუშვი `upload-to-cloudflare.cmd`, ან:

```sh
npm ci
npm run deploy
```

გამშვები მოგთხოვს Cloudflare-ზე შესვლას, საიტის სახელსა და საკონტაქტო ელფოსტას. პირად ZIP-ში პაროლი წინასწარ მომზადებულია. GitHub-ის ასლში პირადი პაროლის ფაილი არ შედის, ამიტომ პირველ გამართვაზე მიუთითე შეთანხმებული პაროლი.

გამშვები ქმნის D1 საცავს, ცხრილებს, Web Push გასაღებებსა და ყოველდღიურ განრიგს. სრული ინსტრუქცია იხილე [START-HERE.txt](START-HERE.txt).

პაროლი ინახება Worker-ის `APP_PASSWORD` secret-ში. `.initial-password`, `.dev.vars` და `deployment-secrets.json` პირადი ფაილებია და Git-ში არ შედის.

## ლოკალური შემოწმება

```sh
npm ci
node scripts/prepare-dev.mjs
npm run db:local
npm run dev
```

მისამართი: `http://127.0.0.1:8791`. GitHub-ის სუფთა ასლის ლოკალური საცდელი პაროლია `local-test-123`. საიტი ცარიელი შეკვეთების სიით იწყება; საჩვენებელი შეკვეთები არ არის.

```sh
npm test
npm run test:ui
npm run build
```

ბრაუზერის ტესტებისთვის საჭიროა Google Chrome. წარმოების ტელეფონზე Push შეტყობინება უნდა შემოწმდეს განთავსებისა და შეტყობინებების ნებართვის მიცემის შემდეგ.
